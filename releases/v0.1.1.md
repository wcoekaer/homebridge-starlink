First public release of Homebridge Starlink: local dish health sensors and a graphical telemetry dashboard in Apple Home.

### Included

- Three HomeKit contact sensors: Outage, Degraded, and Monitor Unreachable, with configurable confirmation and recovery delays.
- Dashboard camera with snapshots and live H.264 video showing latency, packet loss, throughput, power, dish health, and recent interruptions.
- Homebridge configuration UI and child-bridge support.
- Read-only local Starlink gRPC telemetry; no Starlink cloud account or API key required.

### Fixes in 0.1.1

- Fix live-camera startup when the HomeKit control and video connections use different IP families, including IPv4-mapped IPv6 addresses.
- Show camera startup failures and the last stale-telemetry error in normal Homebridge logs.
- Report the installed plugin version in HomeKit accessory information.

### Install or upgrade

Download **homebridge-starlink-0.1.1.tgz** from the release assets and copy it to the machine running Homebridge. From that Homebridge installation's terminal:

```sh
npm install -g /absolute/path/homebridge-starlink-0.1.1.tgz
```

Restart Homebridge or the Starlink child bridge. Existing installations retain their configuration and HomeKit pairing. For a new installation, configure the Starlink platform in the plugin UI, set up its child bridge, and pair that bridge in Apple Home.

Use the `.tgz` asset for installation; GitHub's automatically generated source archives do not contain the compiled plugin. `SHA256SUMS` provides the installation archive's checksum.

### Requirements

- Homebridge 1.8+ or 2.x and Node.js 22.12+, 24, or 26.
- The Homebridge host must reach the dish at `192.168.100.1:9200`. Multi-WAN setups may need a dish-specific route, including an exception to any per-device WAN policy.
- FFmpeg for live video. A supported binary is supplied by the optional dependency; a custom path is configurable. JPEG snapshots and sensors work independently of FFmpeg.

The camera supports HomeKit snapshots and live video; it does not provide HomeKit Secure Video recording or audio. Missing telemetry is shown as unavailable rather than as a confirmed Internet outage.

### Validation

- All 18 automated tests passed, including telemetry handling, sensor behavior, and encrypted video decoding.
- Packaged camera streaming and child-bridge startup verified with Homebridge 2.4.0 / HAP 2.2.2.
- Dish connectivity, telemetry, and Home app playback confirmed on a real installation.
